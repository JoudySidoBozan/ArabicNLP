# Quick Start

**Use after:** [installation-guide.md](installation-guide.md)  
**Goal:** open the first notebook and run one cell successfully

Use this page after you have completed [installation-guide.md](installation-guide.md).

> **Success marker:** JupyterLab opens in your browser and the first code cell in `00_welcome_and_navigation.ipynb` prints output.

## Open the Workshop

1. Open Terminal or Anaconda Prompt.
2. Move into the repository folder with `cd`.
3. Activate the workshop environment:

   ```bash
   conda activate arabic-studies-nlp-workshop
   ```

4. Start JupyterLab:

   ```bash
   jupyter lab
   ```

5. In the browser window, open `notebooks/00_welcome_and_navigation.ipynb`.

## Run a Cell

1. Click the first code cell.
2. Press the play button, or press `Shift+Enter`.
3. Look underneath the cell for output.
4. Continue one cell at a time from top to bottom.
