# Quick Start

**Use after:** [installation-guide.md](installation-guide.md)  
**Goal:** open the shared Colab notebook and run one cell successfully

> **Success marker:** the Colab notebook opens in your browser and a code cell can run.

## Open the Workshop

1. Open the shared Colab notebook:
   <https://colab.research.google.com/drive/1Y3qCbD6Gw1KEw-lixQx1rI6WlyWnrnDS?usp=sharing#scrollTo=X3KV4vNDDtG8>
2. Sign in to your Google account if prompted.
3. Save a copy to your Drive if Colab asks you to.
4. Read the notebook from top to bottom.

## Run a Cell

1. Click the first code cell.
2. Press the play button, or press `Shift+Enter`.
3. Look underneath the cell for output.
4. Continue one cell at a time from top to bottom.
