What This Workshop Does

This workshop introduces Arabic NLP as both a practical method and an object of scholarly critique. You will learn how to open a notebook, run short pieces of code, inspect Arabic text as data, and ask careful questions about what computational outputs can and cannot show.

Core principle: technical practice and critical interpretation belong together. We will ask what the tools do, what they miss, and what a responsible scholarly claim requires.

Learning Goals

Use the workspace

Open JupyterLab, identify code and markdown cells, run cells in order, and recover from common beginner errors.

Inspect Arabic text

Recognize strings, Unicode, characters, whitespace tokens, diacritics, and basic display issues.

Explore a corpus sample

Load a small OpenITI/KITAB-style sample, inspect metadata, count word forms, and search for context.

Interpret responsibly

Discuss preprocessing, dialect representation, OCR, corpus selection, model prediction, bias, and evidence.
