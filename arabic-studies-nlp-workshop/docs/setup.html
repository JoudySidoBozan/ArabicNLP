Before the workshop

Prepare Your Laptop

These steps create a separate Python environment for the workshop and open JupyterLab in your browser.

If setup fails: bring your laptop anyway. You can still follow the workshop through the instructor's screen or by pairing with someone whose setup works.

Setup Overview

Step Action Success marker
1 Install Miniconda or Anaconda conda --version prints a version number
2 Open Terminal or Anaconda Prompt You can type commands
3 Move into the workshop folder README.md and environment.yml are visible
4 Create and activate the environment The prompt shows arabic-studies-nlp-workshop
5 Start JupyterLab A browser window opens

Commands

Open Terminal on macOS or Linux. On Windows, open Anaconda Prompt.

Move into the workshop folder. If the folder is on your Desktop, the command may look like this:

cd Desktop/arabic-studies-nlp-workshop

Check that you are in the right place:

ls

On Windows Anaconda Prompt, use:

dir

Create the workshop environment:

conda env create -f environment.yml

Activate it:

conda activate arabic-studies-nlp-workshop

Start JupyterLab:

jupyter lab

Troubleshooting

Symptom First thing to check
conda is not recognized Use Anaconda Prompt on Windows, or reopen Terminal after installing Conda.
environment.yml is missing Move into the arabic-studies-nlp-workshop folder.
camel_tools does not import Activate arabic-studies-nlp-workshop.
JupyterLab does not open Copy the http://localhost: link from the terminal into your browser.
A notebook cell runs for a long time It may be downloading a model. Ask before interrupting it.

If Technology Fails

Installation problems are common in first digital methods workshops. The workshop can continue even if not every laptop works perfectly.

Problem Workshop response
Many installations fail Follow from the shared screen and focus on concepts, outputs, and interpretation.
Some installations fail Pair with someone whose setup works, or continue conceptually until the next pause.
Internet is slow Skip live model downloads and discuss model behavior conceptually.
JupyterLab fails Read notebooks as structured documents and compare expected outputs with the shared screen.
Remember: the core goal is to understand the workflow and its limits, not to prove that every computer can run every package during the session.
