Workshop route

Six-Hour Schedule

The workshop moves from basic notebook navigation to Arabic text analysis, corpus exploration, model interpretation, and critical reflection.

Timeline

Notebook Order

Welcome and navigation

Learn notebooks, cells, output, folders, and the workshop map.

Arabic text basics

Work with strings, Unicode, characters, diacritics, and whitespace tokens.

Tokenization and normalization

Compare simple splitting with Arabic-aware tokenization and preprocessing.

Corpus exploration

Load a small text sample, inspect metadata, count words, and search context.

Arabic models

Run or discuss a masked language model demonstration and its limits.

Bias, power, and reflection

Connect technical outputs to corpus selection, dialects, digitization, and interpretation.

Pacing and Flexibility

If time is short

We will shorten the model demonstration, keep optional code edits instructor-led, and preserve the final reflection rather than spending all remaining time on technical troubleshooting.

If time remains

We can explore the sample corpus further, change query words, compare results, and use the glossary or optional readings for next-step questions.

Essential orientation

The welcome and navigation notebook is part of the method. It builds the basic mental model of notebooks, cells, files, output, and errors.

For the live workshop, keep this schedule open next to JupyterLab.
