Participant Guide

Key vocabulary

Terminal or Anaconda Prompt: a text-based way to ask your computer to open tools.

Conda: a tool that creates a separate workshop environment.

JupyterLab: a browser-based workspace where you run notebooks.

Notebook basics

Read notebooks from top to bottom. Markdown cells explain; code cells run. To run a code cell, click it and press the play button or Shift+Enter.

If something breaks

Use Kernel > Restart Kernel, then run cells again from the top. Errors are normal in a methods workshop.
