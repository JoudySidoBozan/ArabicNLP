# Data Notes

**Purpose:** small teaching data for workshop exercises  
**Research status:** demonstration only, not a representative corpus

This folder contains small sample files to support the workshop. The data is intended for learning and demonstration, not for research.

| Folder | Contents | Workshop use |
| --- | --- | --- |
| `raw/` | Original sample texts with minimal preprocessing | Reading, searching, and first frequency counts |
| `cleaned/` | Small cleaned version used by notebooks | Comparing raw and processed text |
| `metadata/` | Example metadata | Discussing provenance and corpus structure |

## Data philosophy

We use sample OpenITI-style and KITAB-style text in the notebooks to demonstrate corpus exploration and textual analysis. These files are intentionally short so participants can run analysis quickly.

> **Academic caution:** the sample files should not be treated as a representative corpus of Arabic. They are teaching materials for learning how text files, metadata, tokenization, and frequency counts work.

Any scholarly interpretation would require a larger corpus, clearer provenance, and domain-specific contextual analysis.
