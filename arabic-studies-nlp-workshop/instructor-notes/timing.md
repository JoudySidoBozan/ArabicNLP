# Timing Guide

**Use with:** [teaching-plan.md](teaching-plan.md)  
**Total time:** 6 hours, including break and buffer

This workshop is designed for 6 hours with breaks.

| Time | Segment | Main output |
| --- | --- | --- |
| 20 min | Welcome, expectations, and setup check | Everyone knows the workshop route |
| 35 min | `00_welcome_and_navigation` | Participants can run a cell |
| 50 min | `01_arabic_text_basics` | Participants can inspect Arabic strings |
| 50 min | `02_tokenization_and_normalization` | Participants can compare preprocessing outputs |
| 30 min | Break | Reset and support installation issues |
| 50 min | `03_corpus_exploration_openiti` | Participants can count and search a sample |
| 40 min | `04_intro_to_arabic_models` | Participants can describe model limits |
| 50 min | `05_bias_power_and_reflection` | Participants write and discuss a reflection |
| 25 min | Final discussion and next steps | Participants know where to continue |
| 10 min | Buffer | Absorb delays |

## Flexibility

If time is short:
- shorten the model demo to the conceptual section;
- skip optional code edits and keep instructor-led examples;
- preserve the final reflection rather than using all remaining time for technical debugging.

If time remains:
- explore the sample corpus further;
- ask participants to modify a query word and compare results;
- review the glossary and optional readings.

## Pacing Note

For participants new to digital methods, `00_welcome_and_navigation` is not optional. It is where learners form a mental model of notebooks, cells, files, and output.
