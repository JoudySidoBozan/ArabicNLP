# Readings

**Purpose:** orientation before the workshop and continuation afterward

This folder groups short reference materials for the workshop.

| Folder | Use |
| --- | --- |
| `essential/` | Starting points for Arabic NLP, corpora, and digital humanities |
| `optional/` | Longer readings, technical background, and critical perspectives |
| `glossaries/` | Key terms used in the notebooks and discussion |

Participants do not need to read everything before the workshop. The essential readings are meant to provide orientation; the optional readings are for continuing study afterward.
