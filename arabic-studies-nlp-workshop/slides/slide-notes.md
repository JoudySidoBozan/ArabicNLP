# Slide Companion Notes

**Purpose:** outline for a professional, beginner-friendly slide deck  
**Use with:** live notebooks, not instead of them

This repository includes `workshop-slides.pdf`. The slide deck should cover:

| Slide group | Purpose |
| --- | --- |
| Title and learning goals | Establish scope and expectations |
| What NLP is and is not | Prevent tool mystification |
| What a notebook is | Prepare participants for JupyterLab |
| Repository map | Show where files live |
| Arabic script and Unicode basics | Introduce text as computational data |
| Tokenization and normalization | Connect code to linguistic choices |
| OpenITI/KITAB corpus examples | Move from sentence to corpus |
| Arabic model concepts and limits | Introduce prediction without overclaiming |
| Bias, power, and representation | Frame critical interpretation |
| Practice prompts | Transition from slides to notebooks |

For a beginner audience, avoid slides that are mostly code. Use slides to establish concepts and vocabulary, then use notebooks for live interaction.

## Visual Style

| Element | Recommendation |
| --- | --- |
| Layout | Use one concept per slide |
| Text | Prefer short definitions and questions |
| Code | Show only tiny snippets, then move to notebooks |
| Arabic examples | Use large, readable text with generous spacing |
| Diagrams | Use simple process diagrams: text, preprocessing, output, interpretation |
| Critical slides | Pair technical output with an interpretive question |
