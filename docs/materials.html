Participant Guide

Key vocabulary

Google Colab: a browser-based workspace where you run notebooks without installing Python locally.

Google Drive: the storage connected to your Google account, used for saving your Colab copy and files.

Runtime: the temporary computer in the cloud that runs your notebook code.

Notebook basics

Read Colab notebooks from top to bottom. Markdown cells explain; code cells run. To run a code cell, click it and press the play button or Shift+Enter.

If something breaks

Use Runtime > Restart session, then run cells again from the top. Errors are normal in a methods workshop.

Workshop Exercises

Use these tasks to connect common Arabic studies research questions with appropriate NLP and computational text analysis approaches.

Task 1

NLP Tasks

Select the right NLP task for each common research question.

Research Question Select an Analytical Approach Result
Who was the actual author of text x?
Which thematic focuses can be identified in text x or corpus y, and how do they change over time?
How is a specific topic represented or evaluated in text x or corpus y?
Which entities, such as places, persons, or organizations, appear most frequently in text x or corpus y?
What kinds of relationships exist between these entities?
Which references, allusions, or intertextual connections can be found between texts or within a text?
How do different versions of a text differ, and how similar are two texts?
How do texts differ across periods, genres, or languages?
